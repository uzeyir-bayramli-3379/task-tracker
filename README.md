# Task Tracker

A simple, lightweight task tracker built as a single HTML page. Add tasks, mark them done, and clear them out — no accounts, no setup, no clutter.

🔗 **Live demo:** [task-tracker-navy-five-21.vercel.app](https://task-tracker-navy-five-21.vercel.app)

Deployed on Vercel.

## Features

- Add new tasks quickly
- Mark tasks as complete
- Delete tasks you no longer need
- Clean, minimal interface
- Runs entirely in the browser — no backend required

## Tech Stack

- **HTML** for structure
- **CSS** for styling
- **JavaScript** for interactivity

Everything lives in a single `index.html` file, so there's no build step or dependencies to install.

## Getting Started

Clone the repo:

```bash
git clone https://github.com/uzeyir-bayramli-3379/task-tracker.git
cd task-tracker
```

Then open `index.html` in your browser:

```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

That's it — no server or install required.

## Deployment

The app is deployed on [Vercel](https://vercel.com). To deploy your own copy, import the repository into Vercel and it will serve `index.html` automatically as a static site.
